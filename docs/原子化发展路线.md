## 2. 原子化切片原则

每个切片固定包含 6 个部分：

1. **学习目标**：本切片学什么概念。
2. **实现目标**：只做一个最小功能。
3. **修改文件**：提前限制范围。
4. **验证命令**：必须能本地验证。
5. **完成标准**：明确什么叫完成。
6. **复盘问题**：做完后写 2-3 句总结。

切片大小要求：

- 后端切片：最好 20-80 行代码改动。
- 前端切片：一个页面或一个 client 方法，不混做样式大改。
- C++ 切片：一个 action 分支、一个错误分支或一个 helper，不混做系统重构。
- Godot 切片：一个按钮、一个请求、一个事件展示，不混做场景美术。

禁止：

- 一次同时改 C++ 规则、FastAPI、React、Godot。
- 测试失败时继续叠新功能。
- 文档已经声明接口但代码没有对应测试。
- 只手测不写最小自动化测试，除非是 Godot 场景表现。
